# Google Play 提出の入力メモ（コピペ用）

Play Console（https://play.google.com/console）→ 「アプリを作成」から。

## 1. アプリを作成
| 項目 | 入力 |
|---|---|
| アプリ名 | 地理王 |
| デフォルトの言語 | 日本語 |
| アプリ／ゲーム | ゲーム |
| 無料／有料 | 無料 |
| 申告 | デベロッパー プログラム ポリシー、米国輸出法に同意 |

## 2. 「ダッシュボード」→「アプリのセットアップ」（すべて完了させる）
| 項目 | 入力 |
|---|---|
| プライバシー ポリシー | https://geoking-vlgh.onrender.com/static/privacy.html |
| アプリのアクセス権 | 「すべての機能が特別なアクセス権なしで利用可能」 |
| 広告 | 「いいえ、広告を含みません」 |
| コンテンツのレーティング | メールアドレスを入力 → カテゴリ「ゲーム」→ 質問はすべて「いいえ」、ただし「ユーザー同士のやり取り（チャット）」は「はい」→ フィルタあり。結果は IARC 3+ 相当 |
| ターゲット ユーザー | 13歳以上（子ども向け設計ではない）。「子どもの興味を引く可能性」は「いいえ」 |
| ニュースアプリ | いいえ |
| データ セーフティ | 下記 |
| 政府アプリ | いいえ |
| 金融機能 | 「該当なし」 |
| 健康 | 「該当なし」 |

### データ セーフティの回答
- データを収集または共有するか：**はい**（ニックネームとチャットをサーバーに送るため）
- 収集するデータ：
  - 「個人情報 ＞ 名前」…**ニックネーム**。収集のみ（共有なし）、一時的な処理（保存しない）、必須、目的「アプリの機能」
  - 「メッセージ ＞ その他のアプリ内メッセージ」…チャット。収集のみ、一時的、任意、目的「アプリの機能」
- データは暗号化して送信：はい（HTTPS）
- 削除をリクエストする手段：はい（部屋を出ると即時削除）
- 端末ID・位置情報・連絡先など：収集しない

## 3. 「ストアの設定」→「メインのストアの掲載情報」
| 項目 | 入力 |
|---|---|
| アプリ名 | 地理王 |
| 簡単な説明（80字） | 国旗だけを見て「面積が大きい国は？」に答える、みんなで遊べる地理カードゲーム。 |
| 詳しい説明 | 下記 |
| アプリのアイコン | `docs/store-assets/icon-512.png` |
| フィーチャー グラフィック | `docs/store-assets/feature-1024x500.png` |
| スマートフォンのスクリーンショット | `docs/store-assets/promo/play-1.png` 〜 `play-4.png` |
| 7インチ／10インチ タブレット | 任意（スマートフォンのものを流用可） |

### 詳しい説明
国旗カードを8枚配られ、「面積が大きい国は？」「年平均気温が高い国は？」「イスラム教徒の割合が高い国は？」といったお題に、裏面のデータを見ずに一番合いそうな国旗を出します。めくって、最もお題に近い人が1点。7ラウンドで一番多く取った人が「地理王」。

■ 特徴
・197の国と地域の国旗と、面積・人口・GDP・気温・降水量・宗教・寿命など約30種のデータ
・友だちと部屋コードで対戦。公開部屋で世界の誰かとも
・途中入室は観戦モード。誰がどのカードを選んでいるかがリアルタイムで見える
・国旗をタップすると国のデータと世界地図上の位置を表示
・知識がなくても勘で勝てる。外れた分だけ国旗と世界を覚える
・ひとりで遊ぶときはボットを追加

■ 安心して遊べます
チャットは不適切な表現・URL・連絡先を自動で除外。相手のミュート・通報もできます。アカウント登録・課金・広告はありません。

## 4. リリース
1. 「テストと公開」→「内部テスト」→「新しいリリースを作成」
2. 「Play アプリ署名」は Google 管理の鍵を使用（既定）で続行
3. App Bundle に `docs/store-assets/geoking-1.0.0-release.aab` をアップロード
4. リリース名は自動、リリースノート（ja-JP）: 「最初のリリースです。」
5. 「テスター」タブでメールリストにご自身の Gmail を追加 → 内部テストで自分の端末に配布（任意）
6. 問題なければ「製品版」→「新しいリリースを作成」→ 同じ AAB を選び「審査に送信」

## 5. 審査
- 新規アカウントの初回審査は 3〜7 日かかることがある
- 結果はメール。差し戻しは「ポリシー ステータス」に理由が出る
