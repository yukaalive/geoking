# 出来事を Google スプレッドシートに残す（設定の手順）

サーバーは、部屋を作った・入った・出た・ゲームの開始と終了・画面を開いた時刻と滞在時間などを、30秒ごとにまとめてスプレッドシートへ送ります（server.py の `sheet_log`）。
サーバーを更新しても消えません。85日を過ぎた行は、スプレッドシート側で毎日自動で消します（何日か失敗しても、どの行も90日以内に消える）。チャットの中身は残しません。
画面を開いた記録は誰でも送れてしまうので、1分に120行まで（部屋の出来事は600行まで）しか残しません。部屋で断られる名前（電話番号など）は「(名前なし)」にします。

下の設定をするまでは何も送りません（Render の Logs に `sheet log: off` と出ます）。

**バトルのレート（2026-10-03〜）も同じスプレッドシートに残します。** シート「レート」（setup が作る）に、1人1行で、端末ごとの番号（合言葉そのものではない）・名前・レート・試合数・人との試合数・最高のレート・名前を出さないか・更新日時。サーバーは起動したときに全部読み、バトルで変わった人の行を30秒ごとに送ります（同じ番号の行は上書き。試合数が減る古い書き込みは受けない）。最後にバトルしてから1年たった行は、毎日の片付けで一緒に消します。
- 設定する前も、レートは消えにくくしてあります（更新のとき、新しいサーバーが起動の途中で古いサーバーから全部もらう・端末にサーバーの署名つきの控えを持ち、サーバーが忘れていたら戻す）。ただ、Render の無料プランが15分使われずに眠ると、全国ランキングは「眠ったあとに遊びに来た人」だけになります。設定すると、起動したときに全員分を読みます
- 設定したあと最初に起動したサーバーは、そのとき持っているランキング（設定する前に遊んだ人・古いサーバーからもらった人）を、シートにない分だけ書き写します
- 前にこのページの手順で設定した人は、`Code.gs` を貼り直して保存し、ウェブアプリを「新しいバージョン」でデプロイし直してください（アドレスは変わりません）。setup をもう一度実行すると、シート「レート」ができます

## 順番（大事）
ニックネームを保存するようになるので、**先に申告を直してから** 送り始めます。
1. Render で Manual sync（プライバシーポリシーの書き足しが公開される）
2. App Store Connect の「App のプライバシー」と、Play Console の「データ セーフティ」を直す（答え方は `docs/appstore-submission.md` の 3、`docs/googleplay-submission.md` の「データ セーフティの回答」）
   - App Store は「公開」を押せばすぐ変わる
   - Google Play は審査がある。Play Console の「公開の概要」で、データ セーフティの変更が公開済みになる（審査中の変更がなくなる）まで待つ
3. 両方が公開されたら、このページの A → B → C をする

## A. スプレッドシートを作る（5分）
1. パソコンのブラウザで Google ドライブを開き、「新規」→「Google スプレッドシート」。名前は「地理王ログ」など。
   - 個人の Google アカウント（Gmail）で作ってください。会社のアカウントだと、手順 B の「全員」が選べないことがあります。
2. メニューの「拡張機能」→「Apps Script」。
3. 最初から入っている `function myFunction() { … }` を全部消し、このフォルダの `Code.gs` の中身を全部貼り付けて、保存（💾）。
4. 上の関数の選択を「setup」にして「実行」。
   - 「承認が必要です」→「権限を確認」→ 自分のアカウント → 「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）（安全ではないページ）に移動」。
   - 許可する内容の一覧が出たら、いちばん上の「すべて選択」にチェックを入れて「続行」（画面によっては「許可」）。
   - 自分で作ったプログラムなので出る表示です。出るのは最初の1回だけです。
5. 下の「実行ログ」に次の2行が出ます。
   - `書き込みの確認: OK（…）` … **NG と出たら、ここで止めて Claude に伝えてください**
   - `合言葉（Render の SHEET_LOG_KEY に入れる）: …` … この長い文字をコピーしておく（C で使う）
   - 2行が出ずに赤い字のエラーが出たときは、もう一度「実行」して、許可の一覧で全部にチェックを入れる。それでも出るときは、その赤い文をコピーして Claude に伝えてください

## B. ウェブアプリとして公開する（3分）
1. 右上の「デプロイ」→「新しいデプロイ」。
2. 左の歯車「種類の選択」→「ウェブアプリ」。
3. 「次のユーザーとして実行」: **自分**、「アクセスできるユーザー」: **全員**。
4. 「デプロイ」→ 出てきた「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）をコピー。
   - この URL をブラウザで開くと「地理王のログの受け口です」と出れば動いています。
   - URL と合言葉がそろわないと書き込めないので、URL が知られても勝手に書き込まれることはありません。

## C. Render に入れる（3分）
1. Render のダッシュボード → サービス「geoking」→ 左の「Environment」。
2. 「Add Environment Variable」で2つ足す（Manual sync では入らないので、ここで手で入れる）。
   - `SHEET_LOG_URL` … B でコピーした URL
   - `SHEET_LOG_KEY` … A でコピーした合言葉
3. 「Save and deploy」を押す（数分で切り替わる）。
4. 地理王を開いて部屋を作る → 30秒ほどでスプレッドシートの「ログ」シートに行が増えれば完了。
   - 増えないとき: Render の「Logs」で `sheet log:` を探す。`on` なら設定は入っている。`send failed` が出ていたら、その行を Claude に見せてください。

## スプレッドシートを見るときの注意
- 並べ替えや絞り込みは「データ」→「フィルタ表示」→「新しいフィルタ表示を作成」で見る（シートそのものを並べ替えても消す処理は動くが、見るたびに並びが変わって分かりにくい）
- このスプレッドシートは誰とも共有しない（ニックネームが入っているため。プライバシーポリシーに「運営者しか見られない」と書いてある）
- 1行目（見出し）とA列（日時）は書き換えない

## あとで Code.gs を直したとき
「デプロイ」→「デプロイを管理」→ 鉛筆（編集）→「バージョン」を「新バージョン」→「デプロイ」。URL は変わりません。

## 列
日時 ／ 出来事 ／ 部屋コード ／ 部屋名 ／ ニックネーム ／ 人数（ボットも含む） ／ くわしく

出来事の種類:
- 部屋のこと: 部屋作成、部屋名変更（前 → 後）、公開部屋にした／やめた、部屋削除
- 人の出入り: 入室、観戦で入室、退出、退出させた、切断（ロビーで接続が切れた、または対戦中に切れたままホストがロビーに戻した。戻るともう一度「入室」になる）
- ゲーム: ゲーム開始（参加者・ラウンド数。バトルは「／バトル」）、ゲーム終了（勝った人・点数。バトルは残った人の体力を点数の欄に、脱落した人は0）、ゲーム中断
- そのほか: 通報（だれがだれを・理由。発言の中身は残さない）、対戦／図鑑／クイズを開いた・離れた（滞在時間）
