# 地理王で案を出すときの考え方（オブジェクト指向 × ユーザー目線）

ユーザーは、このプロジェクトでは**いつもオブジェクト指向とユーザー目線で考える**ことを求めている（2026-09-26「ユーザ視点に立って、オブジェクト指向でボタンの配置を考えて」、2026-09-27「おぶジェクト思考ベースで、非常によくユーザ視点で考えて」「このプロジェクトでは必ずオブジェクト指向やユーザ目線で考える必要がある」）。
作る側の都合（コードの場所・作りやすさ）から考え始めると、画面に説明や設定が増え、「くどい」「注釈などは不要」と言われる。遊ぶ人が「何を見て、何をしたいか」から考え始める。

## 1. 誰が、どんな場面で使うか（登場人物）

案ごとに、次の人になりきって確かめる。当てはまらない人は理由を書いて外してよい。

| 人 | 場面・気持ち |
|---|---|
| はじめての人 | LINE の招待リンクを開き、名前を入れた数秒後に始まる。説明を読む時間はない |
| ホスト | 友だちに口で説明しながら進める。設定・開始・ロビーへを押す人 |
| いつもの人 | 何度も遊んでいる。毎回出る説明や確認はじゃま |
| 公開部屋の知らない人 | 聞ける相手がいない |
| 途中から来た人・観戦 | いま何が起きているか分からない |
| ひとり（ボット・クイズ・図鑑） | 自分のペースで試したい |
| 英語の人 | 文が長くなる。はみ出し・折り返し |
| 端末 | Android 約412px・iPhone 402px 前後・いちばん狭い 320px。アプリ（Capacitor）と Web。ダークモード |

時間の圧も書く: 選ぶのは30秒、答え合わせは8秒で次へ。その間に読めない説明は、ないのと同じ。

## 2. オブジェクト（画面に出る「もの」）から考える

先に「もの（名詞）」を決め、そのあとで「すること（動詞）」を決める。操作ボタンや説明は、関わる「もの」のそばに置く（離れた所の説明ページや、画面の上の注意書きに頼らない）。

地理王のおもな「もの」と、今あるおもな見え方・操作:

- **部屋**（名前・公開・人数）… 作る・入る・名前を変える・公開する・退出
- **プレイヤー**（名前・ホスト・切断・観戦）… ボットを追加・退出させる・ミュート・通報
- **手札の国旗カード** … 選ぶ（2回タップで決定）・国のデータを見る
- **お題**（「面積が大きい国は？」・大きい方から/小さい方から）
- **ラウンド**（何ラウンド目か・残り時間）
- **答え合わせのカード**（順位・値・+N点・世界順位の金銀銅バッジ）… タップで国のデータ
- **点・最終の順位**（結果発表・出された国の一覧）… 同じメンバーでもう一戦・ロビーへ
- **国**（図鑑・国データの小窓）… 探す・ランキング
- **クイズの問題**（モード・ふつう/激ムズ）… 答える・同じ問題でもう一度

考えること:
- その知識や操作は、どの「もの」に付いているか（例: 「+3点」の意味は答え合わせのカードの点に、「金」の意味はバッジに、難しさはクイズのモードに）
- その「もの」の一覧と詳細（一覧で見せるもの／タップして詳しく見せるもの）
- 同じ「もの」は、どの画面でも同じ見た目・同じ操作にする（例: 国旗をタップすれば、どこでも国のデータが開く）

## 3. 案を作る（案A/B/C）

小さい案から大きい案へ 2〜3 個。それぞれに:
- どの画面の、どの「もの」に、何が増える・変わるか。いつ出て、いつ消えるか（いつもの人に毎回出ないか）
- 実際の文言（日本語と英語）。短く。くどい説明・注釈は入れない
- 人ごとの良い点・悪い点（1 の表の人のうち関係する人）
- 320px・英語・ダークモード・アプリで困らないか
- 手間と、壊しやすい所
- おすすめと、その理由（ユーザー目線で）

文字だけで伝わりにくい配置の案は、簡単な見本（画面の絵）を添える。

## 4. 選んでもらってから作る

- 案を出したら、ユーザーが選ぶまで作らない（「まずは案を」と言われることが多い）。
- 作るときは `geoking-ui-change` スキルの手順（変更前の記録 → 変更 → 比べる・確かめる → 報告）に従う。
- 報告も、ユーザー目線で書く（「〇〇の人が、〇〇のときに、こう見える」）。

## 5. 見落としやすいこと（このプロジェクトで実際にあったもの）

- 同じ名前の部品が別の「もの」にも効く（2026-09-27: ヘッダーの `.top` が結果の1位の行にも効き、1位だけスクロールで動かなかった）。「もの」ごとに名前を分ける
- 状態が変わったときの見え方（切断・つなぎ直し・観戦・途中退出・更新時の引っ越し）。例: 対戦中に切れた人が、ロビーに戻っても「切断」のまま残っていた
- めったに出ないものは、ないのと同じに感じられる（2026-09-27: 金バッジは世界1位だけで「金が出ない」と言われ、トップ10 に広げた）
- 出る場所が増えると、前は起きなかった組み合わせが起きる（金が1位以外のカードにも出るようになり、ダークモードで読めなくなった）
- ユーザーが選んだ配置の例: クイズの「ふつう／激ムズ」は、モード（もの）のカードの中にボタン（すること）を置く案B にした
